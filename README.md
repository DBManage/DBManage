# DB Manage

A sleek, mobile-friendly client/project manager that can be hosted with GitHub Pages.

## Included
- Client name
- Project name
- Vehicle dropdown: Van, Truck, Box Truck, Truck & Van
- Progress dropdown: Create Design, In Progress, Start Printing, Done
- Client / pay amount total
- Project date
- Notes
- Top dashboard with project count, average completion, and weekly total
- Search, edit, and delete
- Data stored locally in the browser
- Installable as a home-screen web app when served over HTTPS

## GitHub Pages
1. Create a new GitHub repository.
2. Upload every file in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under the build/deployment section, select **Deploy from a branch**.
5. Select the main branch and root folder, then save.
6. Open the generated Pages URL on your iPhone in Safari.
7. Tap **Share → Add to Home Screen**.

## Important data note
Projects are stored in the browser's local storage. They do not automatically sync between devices or browsers. Keep a backup/export feature in mind before relying on it for business records.
